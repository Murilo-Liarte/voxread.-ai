# VoxRead AI 🎙️📖

Plataforma web de leitura assistida de PDFs por voz com Inteligência Artificial, destaque sincronizado (BBox Highlighter), flashcards automáticos (Active Recall) e resumo esquemático.

🔗 **Acesso:** [https://murilo-liarte.github.io/voxread.-ai/](https://murilo-liarte.github.io/voxread.-ai/)

## Recursos

- **Leitura Neural Expressiva**: Síntese de voz neural em português sincronizada frase a frase com o documento PDF.
- **Modo Professor por Voz**: Interrupção instantânea para tirar dúvidas contextuais sobre o trecho lido.
- **Active Recall & Resumo Esquemático**: Geração de flashcards por tópico com exportação para Anki e síntese final.
